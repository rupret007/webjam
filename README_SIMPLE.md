# WebJam (Simple Guide)

WebJam lets musicians rehearse online with:
- **Jamulus** for low-latency audio
- **Webex** for video
- A built-in **mixer** for personal volume control

## 1) Install

1. Run the WebJam installer.
2. If prompted, restart your PC.
3. Launch WebJam.

## 2) First Launch

1. Open `Help -> Run Setup Wizard`.
2. Follow the checks and fix anything marked as failed.

## 3) Start a Session

1. Click **Launch Jamulus**.
2. Click **Launch Webex**.
3. Wait for participants to appear in the mixer.
4. Adjust faders/pan/mute/solo as needed.

## 4) Save Your Mix

- Click **Save Mix** to keep your settings.
- Use **Load Mix** later to restore them.

## 5) If Something Fails

Use this order:
1. `Session -> Open Diagnostics Panel`
2. `Help -> Run Setup Wizard`
3. Retry launch actions

## Accessibility

Use `View` menu:
- High Contrast Mode
- Large Text Mode
- Increase/Decrease Text Size

## Startup Options

Use `Startup` menu:
- Run Setup Wizard on startup
- Run Guided Tour on startup
- Reset All UI Preferences

WEBJAM PRIVATE TEST CANDIDATE — PLEASE READ

This WebJam build is ad-hoc signed and is NOT notarized or reviewed by Apple.
Only install it if you downloaded it from the official WebJam GitHub release
and the release checksum matches your download.

Recommended installation
------------------------
1. Drag WebJam.app onto the Applications shortcut in this window.
2. Eject the WebJam disk image, then open WebJam from Applications.
3. If macOS blocks that first launch, open System Settings > Privacy & Security,
   scroll to Security, click Open Anyway for WebJam, and confirm Open.

This app-bundle approval is Apple's supported path for an unidentified app.
Managed Macs may prevent it. Recent macOS versions can block downloaded
`.command` files without offering the same Open Anyway approval, so the
installer helpers below are not the recommended double-click path.

Optional verified installer helpers
-----------------------------------
The two `.command` helpers verify the adjacent app's signature, version, build,
architecture, executable inventory, and transport checksum before installing.
To run one after verifying the release checksum, open Terminal, type
`/bin/bash ` (including the trailing space), drag the chosen helper into the
Terminal window, and press Return.

"Install WebJam.command" preserves quarantine. "Install WebJam - Remove
Quarantine.command" is the advanced path: it displays a warning and removes
Apple's quarantine attribute from the installed WebJam.app only. It does not
disable Gatekeeper globally or change any other application. This is less safe
than Apple's Open Anyway flow.

Neither helper uses sudo. It installs into /Applications when that folder is
writable and otherwise falls back to your personal ~/Applications folder.

Optional Webex conversation
---------------------------
Webex is not bundled with WebJam. After WebJam opens, choose
More > Webex / Conversation. If the native Webex app is missing, Get Webex
opens Cisco's official installer for this Mac after you confirm. Cisco owns
that download, license, installation, sign-in, and its automatic updates.
Jamulus remains the
music path; keep Webex muted while playing to avoid delayed duplicate audio.

iPhone Pocket Stage setup
-------------------------
The "Pocket Stage iPhone Setup" folder contains the exact generated Xcode
project compiled by this candidate's CI run. Install the full Xcode app, add
your Apple ID in Xcode > Settings > Accounts, then double-click "Open Pocket
Stage in Xcode.command". In Xcode, choose your free Personal Team, enter a
unique bundle identifier, connect your iPhone, and press Run. A paid Apple
Developer Program membership and XcodeGen are not required for this
owner-device test. This is source for temporary Personal Team installation,
not a pre-signed or App Store-distributed iPhone app.

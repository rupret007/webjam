WebJam cryptography 50.0.0 upstream-wheel provenance
====================================================

Scope
-----
This record covers the upstream cryptography 50.0.0 binary wheels selected by
WebJam's Windows x64, Linux x64, and Apple-silicon macOS release locks. The
official wheels statically embed OpenSSL 4.0.1. Intel macOS uses the separately
documented WebJam source build and OpenSSL 3.5.7 LTS instead.

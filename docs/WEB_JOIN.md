# Web Join invite and listen-only entry

An invited person opens the link and taps **Join to listen** to enter without
requesting microphone access. To play or talk, use **Check microphone**, confirm
headphones, then choose **Join with microphone**. The current session chooses its
audio direction when it connects. A listener who wants to play can ask the host
for a fresh invite and use the microphone path.

The host sends an invite that is already prepared. **Share invite** calls the
platform share sheet from that click where supported. On the desktop WebJam
card, **Email invite** opens a mail draft and **Copy invite** stays available.
The standalone host dialog is a synthetic share-sheet fixture.

Choosing a known Game Night game still opens the protected page with
`deliver=share`. A pasted guest link or room address does not gain `deliver`.

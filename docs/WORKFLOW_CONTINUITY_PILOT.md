# Workflow continuity pilot — unreleased test build

**Physical pilot status: NOT RUN.** This checklist is for the workflow
continuity PR and its eventual test build after the published v0.29.0 baseline.
The source version remains v0.29.0; that version string alone cannot identify
the new build. No new release, tag, signing, notarization, or public service is
requested by this work. [GitHub Latest](https://github.com/rupret007/webjam/releases/latest)
continues to identify the published packages.

The scope is safe return to the launch screen, local searchable workflow Help,
focused persistence recovery, and bounded CI diagnostics. The existing Session
library, rehearsal plans, Studio review/receipts and Art projects are the
v0.29.0 baseline, not newly invented capabilities. Jamulus retains live audio;
Art users keep their own tools. Help is not a model, a paid API, or peer chat.

## Ten-minute first pass

Use owned sample work and completed takes you are permitted to open. These
short routes exercise navigation; they do not replace the longer physical
music checks below.

| Time | Music | Art |
| --- | --- | --- |
| 0–2 min | Open File → Session library, choose Music and continue saved work. Confirm the title and notes return without starting audio. | Choose an Art workspace and continue it. Confirm the brief, progress and references return without opening another app. |
| 2–4 min | Open F1 or More → Help. Search for saved work or export, read a topic, then use its explicit navigation action. Keep Stop/End reachable. | Search Help for Art references. Selecting a result should only change the help topic. Open the project deliberately. |
| 4–6 min | Preserve both song drafts while moving through a rehearsal plan. A moment without verified take timing remains a plain note. | Select a reference and a manual lesson bookmark; open the reference only when ready. Relink a moved reference deliberately if available. |
| 6–8 min | Review two completed takes with Set A/Set B and Listen A/Listen B. Export reviewed take and inspect the verified receipt. If no takes exist, record NOT RUN for this step. | Save the Art workspace, reopen it, and check the same progress and reference identity. Export a summary to a new file. |
| 8–10 min | After ending/leaving any room, choose File → Return to launch. Choose File → New Music Project… at the fresh launch screen. Confirm no old invitation or audio action replays. | After ending/leaving the Art room, return to launch. Reopen the saved project without starting a new room or opening a reference. |

If a save, finalization or cleanup fails, retain the current work and resolve
that condition; returning to launch must not discard it. Cancellation must not
silently reconnect or replay the previous startup choice.

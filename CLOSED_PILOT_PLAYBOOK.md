# WebJam v0.16 closed pilot

The pilot validates a simple rehearsal experience:

1. Host or Join.
2. Native Jamulus sound setup.
3. Human sound confirmation.
4. Optional Webex.
5. Invite/play/record/review.

Keep the scope honest. Automated checks validate source and package behavior.
Two-Mac audio, interface loss, sleep/wake, take recovery, Local Originals, and
external-editor import require real musician observations.

Use the v0.16 worksheet for package identity and outcomes. Preserve v0.15.0 as
the rollback package until v0.16 package and physical checks are complete.
